JavaScript Lecture - Practical Examples

1. slice()

الفكرة: نستخدم slice() لقص جزء من النص. البداية تدخل في القص، لكن النهاية لا تدخل.

2. substring()

الفكرة: substring() تشبه slice، وتستخدم لاقتطاع جزء من النص.

3. الفرق بين slice() و substring()

الفرق المهم: slice() تقبل القيم السالبة، أما substring() لا تتعامل مع السالب بنفس الطريقة.

4. dataset / Custom Attribute

الفكرة: نخزن قيمة داخل العنصر باستخدام data- ثم نصل لها من JavaScript باستخدام dataset.


5. Typewriter Effect

الفكرة: نخزن النص داخل data-text، ثم نعرضه حرفًا حرفًا باستخدام setInterval.

6. إظهار input حسب اختيار select

الفكرة: كل option لها value، وكل input له data-group. إذا كانوا متساويين، نظهر input المناسب.

7. فلترة الصور باستخدام Buttons + dataset

الفكرة: كل زر له id، وكل صورة لها data-image. إذا كانت قيمة data-image تساوي id الزر، تظهر الصورة.
